# Clasă (class.html, one class)

Scope: a single class page for the teacher and the student: the hero plate, the tab row, and the tabs Sumar, Mesaje, Teme, Simulări, Tablă, Catalog (Cabinet Personal for a student), with their dialogs. A style-only pass on purpose: the structure stays, the user asked for style, colour, alignment, elements, more animation, 3D keys and a Mesaje tab whose writing box is always visible. NOT the live whiteboard view, the simulation runner or the editors (legacy; they only pick up the remapped variables). Visitor mode: Operate. Constraints: every function and Supabase call unchanged, Romanian copy, no em dash in UI copy, light + dark, calculator world from DESIGN.md.

## Direction contract

THESIS: A class is a small instrument with its own display: the plate shows the week and counts down to the next lesson, the tabs are keys, the figures are on displays, everything else is a hard-edged panel. Refuses the category default of a gradient hero with floating orbs, glass panels and pastel status pills.

OWN-WORLD: The shared calculator world: graph-paper chassis ground, Panels on a 4-5px edge, keys that sink, green-gray LCD (backlit at night) with dot-matrix figures, the navbar's calm blue; outlined 2px-corner legends instead of pills; three chat voices (key face, lit blue, display).

STORY: The teacher opens a class, reads the plate (program, next lesson, code), reads the totals, scans who needs attention; in Mesaje the whole conversation and the box to type in are on screen at once. The student lands on the conversation, sees homework as panels with a state square and a due legend, and reads their own figures on a display.

FORM: Plate + tab keys + panels and displays; no structural change. Signature interactions: the live program display (seven-day week with the class's days lit, a stepped countdown clock), the figures counting up on the displays, panels dealt in on tab open, a labelled composer with a real Trimite key that stays in view.

MOTION: load sequence (plate fades, displays run the segment test, tab keys drop in one by one, panels dealt with a stagger, figures count up), gated to the first 1.6s after a page or tab opens; key press sink; stepped clock. Reduced motion renders static.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict and DESIGN.md.
